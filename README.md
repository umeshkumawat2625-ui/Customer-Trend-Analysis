# Customer Trend Analysis

## 📌 Project Overview

Customer Trend Analysis is a data analytics project focused on understanding customer purchasing behavior, product performance, discount usage, subscription patterns, and revenue contribution using SQL.

The project uses customer shopping data to answer business questions and extract insights that can help businesses understand their customers, evaluate purchasing trends, and make data-driven decisions.

## 🎯 Project Objectives

- Analyze revenue generated by male and female customers.
- Understand customer spending behavior when discounts are applied.
- Identify products with the highest average review ratings.
- Compare purchasing amounts across shipping methods.
- Evaluate spending patterns of subscribers and non-subscribers.
- Identify products with the highest discount rates.
- Segment customers based on previous purchases.
- Find the most purchased products within each category.
- Analyze subscription behavior among repeat buyers.
- Calculate revenue contribution by age group.

## 🛠️ Tools & Technologies

- **SQL** — Data analysis and business query development
- **PostgreSQL** — SQL syntax used in the queries
- **CSV** — Dataset storage and input format

## 📂 Dataset

The project uses a customer shopping behavior dataset containing information about customers, purchases, products, discounts, shipping, subscriptions, and reviews.

Key fields referenced in the SQL queries include:

## 🔍 Business Questions & SQL Analysis

### 1. Revenue by Gender
Compare total revenue generated by male and female customers.

### 2. Discount Usage and Spending
Identify customers who used discounts but spent at least as much as the average purchase amount.

### 3. Top-Rated Products
Find the five products with the highest average customer review ratings.

### 4. Shipping Method Comparison
Compare average purchase amounts for Standard and Express shipping.

### 5. Subscription Analysis
Compare customer counts, average spending, and total revenue between subscribers and non-subscribers.

### 6. Product Discount Rates
Identify the five products with the highest percentage of purchases involving discounts.

### 7. Customer Segmentation
Classify customers based on previous purchases:
- **New:** 1 previous purchase
- **Returning:** 2–10 previous purchases
- **Loyal:** More than 10 previous purchases

### 8. Top Products by Category
Identify the three most-purchased products within each category using SQL window functions.

### 9. Repeat Buyers and Subscriptions
Analyze subscription status among customers with more than five previous purchases.

### 10. Revenue by Age Group
Calculate total revenue generated by each customer age group and rank the groups by revenue.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open PostgreSQL or another compatible SQL environment.
3. Create a table named `customer` using the columns and data types in the CSV dataset.
4. Import `customer_shopping_behavior.csv` into the `customer` table.
5. Open `customer_behavior_sql_queries.sql`.
6. Execute the queries to explore customer trends and answer the business questions.

**Note:** The SQL queries use PostgreSQL-style syntax, including `::numeric` casting.
